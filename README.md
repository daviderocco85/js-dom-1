# JS DOM 1

DOM Manipulation with JavaScript

# Target

This project is a simple JavaScript-based interaction that simulates turning a lamp on and off by clicking a button.The lamp image switches between a white bulb (off) and a yellow bulb (on).

# Features

- Toggle lamp state (on/off) with a single button.
- Dynamic image switching.
- Bootstrap button color change.
- Centered layout using Bootstrap utilities.
- Clean and minimal JavaScript logic.

# How to run

Clone or download the project.
Open index.html in your browser.
Click the Accendi / Spegni button to toggle the lamp state.
